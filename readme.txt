A simple, lightweight floating social media icons bar with a full admin settings screen. No external icon fonts or CDNs.

== Description ==

Floating Social Media Icons adds a customizable bar of social icons that floats along the side of your site. Configure everything from **Settings > Floating Social Icons**:

* Choose whether the bar floats on the left or right side of the screen
* Set its distance from the top of the page
* Add any number of social networks with their own link URLs: Facebook, Instagram, X (Twitter), YouTube, LinkedIn, Pinterest, TikTok, WhatsApp, Email, and RSS
* Control icon size, shape (circle / square / icon only), spacing between icons, and colors (icon, background, hover)
* Optionally hide the bar on small screens, with a configurable breakpoint

All icons are bundled as inline SVG, so nothing is loaded from a third-party CDN.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install the zip via Plugins > Add New > Upload Plugin.
2. Activate the plugin through the "Plugins" screen in WordPress.
3. Go to Settings > Floating Social Icons to add your social links and adjust the appearance.

== Frequently Asked Questions ==

= Can I add more than one icon for the same network? =
Yes. Each row in the settings screen is independent, so you can add as many icons and links as you like.

= Does this load any external scripts, fonts, or icon libraries? =
No. All icons are inline SVG bundled directly with the plugin.

= Can I control what happens on mobile? =
Yes, there's a toggle to hide the bar below a screen-width breakpoint you set.
